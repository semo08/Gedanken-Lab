# 설계: 용어 주석 (말풍선)

- 날짜: 2026-11-11
- 배경: 이슈 #6 "다음에 할 일" · 용어 주석 기능. 비전공자가 어려운 용어를 눌러서 뜻을 볼 수 있게 한다.

## 1. 동작

- 본문 속 용어는 `<button type="button" class="term" data-term="키">`. 점선 밑줄 + 작은 ⓘ.
- 누르면 용어 위에 말풍선이 뜬다(위에 자리가 없으면 아래). 화면 양옆 16px 안쪽으로 맞추고, 꼬리는 용어를 가리킨다.
- 닫기: 같은 용어 다시 누르기, 말풍선 밖 누르기, `Esc`(누른 용어로 포커스 복귀). 다른 용어를 누르면 그 용어로 바뀐다.
- 말풍선은 페이지에 하나(`#term-pop`). 버튼은 `aria-expanded`, `aria-controls="term-pop"`.
- JS가 없으면 버튼은 그냥 글자처럼 보인다(눌러도 아무 일 없음).

## 2. 코드

- `js/glossary.js`: `GLOSSARY` 데이터(키 → `{ term, text }`). 같은 용어는 실험이 달라도 같은 설명.
- `js/terms.js`: 말풍선 동작. 문서 전체에 이벤트 위임이라 따로 초기화 목록이 없다. 각 실험 페이지에서 `<script type="module">`으로 불러온다.
- `css/base.css`: `.term`, `.term-pop`.
- 테스트(`tests/glossary.test.mjs`): 모든 `experiments/*/index.html`의 `data-term`이 `GLOSSARY`에 있고, `GLOSSARY`의 모든 키가 한 번 이상 쓰인다.

## 3. 용어 14개

각 페이지에서 처음 나오는 정적 문장에만 단다. JS가 그리는 문장(입장 카드, 판정 문구 등)은 이미 설명이 붙어 있어서 뺀다.

| 실험 | 용어 (위치) |
|---|---|
| 트롤리 | 공리주의, 의무론 (결과 게이지 양 끝) |
| 슈뢰딩거 | 방사성 붕괴, 중첩 (소개), 결어긋남 (고찰) |
| 맥스웰 | 열역학 2법칙, 엔트로피 (소개), 비트 (결과 기록), 란다우어 원리 (고찰 연표의 kT ln 2) |
| 쌍둥이 | 상대성이론 (소개), 시공간, 가속 (고찰) |
| 이미테이션 | 대규모 언어 모델 (결과의 GPT-4.5) |
| 중국어 방 | 튜링 테스트, 대규모 언어 모델 (고찰) |
