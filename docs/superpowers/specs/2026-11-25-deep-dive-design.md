# 심화 장면 ("한 단계 더") 설계

책을 읽지 않은 친구의 피드백("조금 더 어려운 문제도 있었으면")에서 나왔다. 기본 실험은 입문자용으로 그대로 두고, 결과 화면 끝에 **고를 수 있는 심화 장면**을 붙인다. 이번에는 공통 구조를 만들고 트롤리(#01)와 쌍둥이(#04)에 첫 심화를 넣는다. 나머지 실험은 같은 구조로 나중에 붙인다.

## 1. 공통 구조

- **진입:** 기본 결과 화면의 "다른 실험 해보기" 바로 위에 진입 카드 `.deep-entry`를 둔다.
  - 구성: 라벨 `심화 · 한 단계 더`, 제목, 한 줄 소개, 버튼 `심화 실험 →`.
  - 카드는 `.card`에 점선 테두리를 더해 "추가 실험"으로 구분한다. 스타일은 `css/base.css`에 있다.
  - 제목과 소개는 레지스트리(`js/experiments.js`의 `deep: { title, teaser }`)에서 가져와 `js/deep-entry.js`가 채운다.
- **화면:** 같은 페이지 안에 `<section data-step="deep-…">`로 추가한다. 진행 표시는 `EXP #01 · 심화 1 / 2`처럼 쓴다.
- **끝:** 심화 결과 화면 맨 아래에 버튼 `← 기본 결과로`(기본 결과 단계로 돌아감)와 "다른 실험 해보기"를 둔다.
- **투표:** 심화는 별도 문서에 저장한다. 기본 투표와 같은 방식이다.
  - 심화 결과 화면에 들어갈 때 투표하고, `localStorage`로 중복을 막는다.
  - 심화 첫 선택 화면에도 투표 안내 `.vote-notice`를 보여 준다.
- **레지스트리와 메인:** 심화가 있는 실험 카드에는 분야 태그 옆에 작은 `심화` 태그를 단다.
  - 메인 페이지(`index.html`)는 수작업 카드라 해당 카드에 직접 넣는다.
  - "다른 실험 해보기" 카드에는 레지스트리를 보고 자동으로 붙인다.
- 심화가 없는 실험은 아무것도 바뀌지 않는다.

## 2. 트롤리 심화: "내 사람"과 "나 자신"

- **진입 카드:** 제목 `선로 위에 내가 아는 사람이 있다면?`, 소개 `숫자는 같다. 달라진 건 누가 서 있느냐뿐이다.`

### 심화 1. 가족이라면 (`deep-1`)

- 상황: 장면 1과 똑같다. 다만 옆 선로에 선 1명이 당신이 가장 사랑하는 사람이다.
- 질문 `레버를 당길 것인가?`
  - A `레버를 당긴다`: 사랑하는 사람이 희생되고 5명이 산다.
  - B `그대로 둔다`: 5명이 희생된다.
- 그림: 장면 1 그림에서 옆 선로의 1명을 하트 표시가 있는 인물로 바꾼다.

### 심화 2. 세 갈래 선로 (`deep-2`)

- 상황: 선로가 세 갈래다.
  - 그대로 가면 5명이 죽는다.
  - 왼쪽으로 당기면 낯선 사람 1명이 희생된다.
  - 오른쪽으로 당기면 선로 옆에 서 있던 당신 자신이 희생된다.
- 질문 `어떻게 할 것인가?`
  - A `그대로 둔다`
  - B `왼쪽으로 당긴다`
  - C `오른쪽으로 당긴다`
- 그림: 세 갈래 선로를 그린다.
  - 위 갈래가 왼쪽(트롤리 진행 방향 기준), 아래 갈래가 오른쪽이다.
  - 갈래 끝에 각각 5명, 낯선 사람 1명, 당신(파랑)이 있다.

### 데이터 (교차 집계)

개인 정보 없이 "장면 1과 비교"를 보여 주려고, 장면 1 답과 심화 답을 합친 키로 저장한다.

| 문서 | 키 | 뜻 |
|---|---|---|
| `votes/trolley_deep_1` | `AA` `AB` `BA` `BB` | 앞 글자 = 장면 1 답, 뒤 글자 = 심화 1 답 |
| `votes/trolley_deep_2` | `AA` `AB` `AC` `BA` `BB` `BC` | 앞 글자 = 장면 1 답, 뒤 글자 = 심화 2 답 |

- `firestore.rules`: 두 문서 ID를 넣고, `keysFor()`에 키 목록을 넣고, 새 키 6개를 모두 `total()`에 넣는다. 콘솔 게시가 필요하다.
- 순수 모듈 `experiments/trolley/deep.js` (테스트 `tests/trolley-deep.test.mjs`):
  - `deepKey(scene1, deepAnswer)`: 저장 키
  - `crossRate(counts, scene1Answer, deepAnswer)`: 장면 1에서 X를 고른 사람 중 심화에서 Y를 고른 비율. 0명이면 `null`.
  - `deepTally(counts, keys)`: 장면 1 답과 상관없이 심화 답별로 합친 수 (세 선택지 막대용)
  - `isSameStance(scene1, deepStep, deepAnswer)`: 장면 1과 같은 방향의 답인지. 심화 2에서는 B와 C가 "당겼다"이다.

### 심화 결과 (`deep-result`)

1. **내 답 비교:** `장면 1: 당겼다 → 가족일 때: 당기지 않았다`처럼 한 줄씩 보여 주고, 바뀐 줄은 강조한다.
2. **다른 실험자들:**
   - 심화 1: `장면 1에서 레버를 당긴 사람 중, 가족이 서 있을 때도 당긴 사람 n%`
   - 심화 2: `장면 1에서 레버를 당긴 사람 중, 자신을 희생하는 쪽을 고른 사람 n%`와 세 선택지 비율 막대
3. **고찰:** 작업 지시서의 문구를 그대로 쓴다. 제목은 `숫자는 같은데, 왜 망설여질까?`
4. **참고 문헌 추가:** Judith Jarvis Thomson, *Turning the Trolley*, Philosophy & Public Affairs (2008)

## 3. 쌍둥이 심화: 닫힌 우주

- **진입 카드:** 제목 `방향을 바꾸지 않아도 나이 차가 날까?`, 소개 `직진만 해도 제자리로 돌아오는 우주에서, 가속이라는 답이 사라진다.`

### 심화 1. 닫힌 우주 (`deep-1`)

- 상황: 한 바퀴가 10광년인 닫힌 우주다.
  - 광속의 80%로 날던 우주선이 지구 옆을 스치며 시계를 맞춘다.
  - 그대로 직진해 한 바퀴를 돌고 다시 지구 옆을 지난다.
  - 아무도 가속하지 않는다.
- 질문 `다시 만났을 때, 누가 더 젊을까?`
  - A `지구에 남은 쪽`
  - B `우주에 다녀온 쪽`
  - C `똑같다`: 가속이 없으니 완전히 대칭이다.
- 그림: 가로 띠 모양의 우주를 그린다.
  - 지구는 띠의 한 지점에 고정되어 있다.
  - 우주선이 오른쪽 끝으로 나가 왼쪽 끝으로 다시 들어와 지구로 돌아온다(약 4초).
  - 경로는 점선으로 늘 그려 두어서, `prefers-reduced-motion`으로 애니메이션을 생략해도 상황이 보인다.

### 데이터

- `votes/twin_deep`, 키 `A`~`C`. `keysFor`의 기존 `A`~`C` 목록에 문서 ID만 더한다.
- 순수 함수 `experiments/twin/relativity.js`의 `loopTrip(circumferenceLy, v)`는 `{ earthYears, shipYears, diffYears }`를 돌려준다.
  - 지구 = 둘레 / v, 우주선 = 지구 / γ
  - 예: 10광년, 0.8 → 지구 12.5년, 우주선 7.5년

### 심화 결과 (`deep-result`)

1. **결과:** `다시 만났을 때, 이번에도 우주에 다녀온 쪽이 더 젊었다`, 지구 12.5년 / 우주선 7.5년, 예측 적중 여부.
2. **다른 실험자들의 예측:** 기본 결과와 같은 막대로 보여 준다.
3. **고찰:** 작업 지시서의 문구를 그대로 쓴다. 제목은 `가속이 없는데 왜 대칭이 아닐까?`
4. **참고 문헌 추가:** John D. Barrow & Janna Levin, *The twin paradox in compact spaces*, Physical Review A (2001)
