# 설계: EXP #02 슈뢰딩거의 고양이 (3단계)

- 날짜: 2026-11-09
- 시각 기준: 트롤리 실험의 실험 노트 스타일(`css/base.css`의 카드, 라벨, 선택 카드, 선 일러스트). 별도 시안 없음.

## 1. 흐름 (`experiments/schrodinger/index.html`, `<section data-step>` 3개)

1. **상황 + 질문**: 상자 일러스트(고양이, 방사성 원자, 가이거 계수기, 독약 병) + 설명. "상자를 열기 전, 고양이는?" 선택 카드 4개(2×2, 좁은 화면 1열).
   - A 살아 있다 · B 죽었다 · C 둘 다 · D 알 수 없다
2. **관측**: 닫힌 상자 + `상자를 연다` 버튼.
   - 열면 뚜껑이 올라가고 결과가 보인다: 살아 있음 / 쓰러짐(X 눈 선화, 잔인하지 않게). `Math.random() < 0.5`.
   - `새 상자 준비`로 다시 닫는다. 누적 기록(칸 + 횟수)이 쌓인다.
   - 3번 이상 열면 `결과 보기`가 나타난다. `← 이전 단계`로 답을 바꿀 수 있다(관측 기록은 유지).
3. **결과**
   1. 나의 입장: 내 답에 해당하는 해석 카드 강조 + 해석 3개 나란히.
   2. 내 관측 기록: N번 중 살아 있음 a번 / 쓰러짐 b번. "한 번의 관측은 하나, 여러 번이면 확률."
   3. 다른 실험자들: A~D 4칸 막대 + 범례 + 참여 수. 실패/0건 처리는 트롤리와 같다.
   4. 고찰: 슈뢰딩거(1935)는 코펜하겐 해석을 비판하려고 이 실험을 고안했다. 실제 거시 물체는 결어긋남으로 중첩이 매우 빨리 깨진다. 어느 해석이 정답인지는 아직 논쟁 중이다.
   5. 참고 문헌: Schrödinger (1935), Einstein·Podolsky·Rosen (1935), Bohm (1952), Everett (1957).
   6. `↺ 다시 실험하기`, "다른 실험 해보기" 섹션.

## 2. 입장 매핑 (`experiments/schrodinger/stance.js`)

| 답 | 입장 키 | 이름 | 한 줄 |
|---|---|---|---|
| A, B | `realism` | 실재론 · 숨은 변수 (아인슈타인, 봄) | 고양이 상태는 이미 정해져 있다. 우리가 모를 뿐이다. |
| C | `many-worlds` | 다세계 해석 (에버렛) | 붕괴는 없다. 두 결과가 각각 다른 세계에서 모두 일어난다. |
| D | `copenhagen` | 코펜하겐 해석 (보어, 하이젠베르크) | 관측 전에는 "실제로 어떤 상태인가"라는 질문 자체에 답이 없다. |

`stance('C')` → `{ key: 'many-worlds', name, line }`. `STANCES`(3개, 표시 순서 고정)도 export한다.
