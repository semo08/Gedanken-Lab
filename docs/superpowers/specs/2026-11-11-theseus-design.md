# 설계: EXP #07 테세우스의 배 (9단계)

- 날짜: 2026-11-11
- 분야: 철학 · 반복 판단 + 입장
- 시각 기준: 기존 실험의 실험 노트 스타일(`css/base.css`). 원래 판자 = 주황 `--a`, 새 판자 = 파랑 `--b`.

## 1. 흐름 (`experiments/theseus/index.html`, `<section data-step>` 4개)

1. **상황**
   - 일러스트: 부두에 정박한 배(옆모습). 선체가 판자 10장으로 나뉘어 보이고, 뱃머리에 이름판 "테세우스".
   - 설명: 영웅 테세우스가 타고 돌아온 배를 아테네 사람들이 기념으로 보존했다. 판자가 썩으면 하나씩 새 판자로 갈아 끼웠다. 그렇게 오래 고치다 보면, 이 배는 언제까지 테세우스의 배일까?(플루타르코스, 『테세우스 전』)
   - `수리 시작 →`
2. **수리** (판자 10장, 한 화면에서 반복)
   - 판자 1장이 빠져서 부두 옆 "헌 판자 더미"로 옮겨지고, 새 판자(파랑)가 그 자리에 들어간다(약 0.8초, `prefers-reduced-motion`이면 즉시).
   - 교체할 때마다 같은 질문: **"이건 아직 테세우스의 배일까?"** 선택 카드 2개: `그렇다` / `아니다`.
   - 진행 표시: "판자 n / 10 교체", 배 그림에서 교체된 판자 수가 그대로 보인다.
   - 교체 순서는 고정(선미 → 뱃머리). **10번째 판자는 이름판이 달린 뱃머리**다. 상징적인 부분을 마지막에 둬서 "마지막 한 장"에서 판단이 바뀌는지 보게 한다.
   - 처음 `아니다`를 고른 순간이 그 사람의 **경계선**이다. 그 뒤로는 묻지 않고 "나머지 판자도 마저 바꾼다" 문구와 함께 남은 판자를 빠르게 교체한다(약 1.5초). 10장 내내 `그렇다`면 경계선은 "끝까지 같은 배"다.
   - 되돌리기는 없다. 매 질문이 "지금 이 순간"의 판단이기 때문이다. 결과 화면 진입 전까지는 투표하지 않으므로 `↺ 처음부터`로 다시 할 수는 있다.
3. **반전: 두 척의 배**
   - 부두 옆에 쌓여 있던 헌 판자 10장이 하나씩 맞춰지면서 두 번째 배가 조립된다(원래 주황 판자만으로). 이제 화면에 배가 두 척 있다.
     - 왼쪽: 계속 수리해 온 배(전부 파랑, 이름판도 새것)
     - 오른쪽: 헌 판자를 모아 다시 만든 배(전부 주황, 원래 이름판)
   - 질문(모든 사람에게, 경계선과 상관없이): **"그럼 진짜 테세우스의 배는 어느 쪽일까?"**
     - A 계속 수리해 온 배
     - B 헌 판자로 다시 만든 배
     - C 둘 다 진짜이거나, 둘 다 아니다
   - 출처 한 줄: 이 변형은 17세기 철학자 토머스 홉스가 덧붙였다.
4. **결과**
   1. 나의 경계선: "당신은 n번째 판자에서 다른 배라고 봤다" 또는 "당신은 끝까지 같은 배라고 봤다". 10번째(뱃머리)에서 바뀌었다면 한 줄 추가: "이름판이 바뀌는 순간 판단이 바뀌었다."
   2. 다른 실험자들의 경계선: 11칸 막대(1~10, 끝까지). 내 칸 강조. 아래에 "n장째까지 같은 배라고 본 사람" 곡선(생존 곡선, 막대 위 꺾은선 또는 별도 막대).
   3. 나의 입장: 반전 질문 답에 해당하는 입장 카드 강조 + 3개 나란히(슈뢰딩거·중국어 방 결과와 같은 방식).
   4. 다른 실험자들의 반전 답: A/B/C 3칸 막대 + 범례 + 참여 수.
   5. 고찰: 물건의 정체성은 재료에 있을까, 이어져 온 역사에 있을까, 우리가 붙인 이름에 있을까? 우리 몸도 세포 대부분이 몇 년에서 십몇 년 사이에 새것으로 바뀐다(대뇌의 신경세포처럼 평생 가는 세포도 있다). 멤버가 다 바뀐 밴드, 부품을 다 바꾼 자동차도 같은 질문이다.
   6. 참고 문헌, `↺ 다시 실험하기`, "다른 실험 해보기".

## 2. 입장 매핑 (`experiments/theseus/stance.js`, 순수)

| 답 | 입장 키 | 이름 | 한 줄 |
|---|---|---|---|
| A | `continuity` | 연속성 입장 | 조금씩 바뀌어도 끊기지 않고 이어져 왔다면 같은 배다. |
| B | `material` | 재료 입장 | 배를 이루는 원래 재료가 있는 곳에 진짜 배가 있다. |
| C | `convention` | 규약 입장 | "같은 배"는 세상에 있는 사실이 아니라 우리가 정하는 이름일 뿐이다. |

`stance('A')` → `{ key, name, line }`. `STANCES`(3개, 표시 순서 고정)도 export한다.

## 3. 로직 (`experiments/theseus/line.js`, 순수)

- `PLANKS = 10`
- `boundary(answers)`: `answers`는 교체마다의 응답 배열(`true` = 그렇다). 처음 `false`가 나온 위치(1부터)를 돌려준다. 끝까지 `true`면 `'KEEP'`.
- `voteKey(boundary)` → `'P1'`~`'P10'` 또는 `'KEEP'`
- `KEYS = ['P1', …, 'P10', 'KEEP']` (통계 막대·`getCounts` 키 목록)
- `survival(counts)`: 각 n(0~10)에 대해 "n장째 교체 뒤에도 같은 배라고 본 사람의 비율". `n`장째에서 같은 배였던 사람 = 경계선이 `n`보다 뒤(`P(n+1)`~`P10`, `KEEP`)인 사람. 0명이면 빈 배열.
- 백분율 막대는 `js/percentages.js`를 쓴다(합이 100).

## 5. 연결

- `js/experiments.js`: `{ num: '07', slug: 'theseus', title: '테세우스의 배', field: '철학', ready: true }`
- `js/other-experiments.js`: `FIELD_COLOR`에 `철학` 추가. 기존 토큰(주황·파랑·잉크)은 이미 다른 분야가 쓰고 있어서, `css/base.css`에 새 토큰 `--c`(짙은 녹색 계열, 예: `#3F6B4F`)를 추가하고 `철학: 'var(--c)'`로 쓴다. 종이 배경 대비 4.5:1 이상인지 확인.
- `index.html`: #07 카드(판자 일부가 파랑으로 바뀐 배 선화 일러스트). 메인 상단 실험 수·소요 시간 갱신.
- 용어 주석(`js/glossary.js`, 결과 고찰 문단에 정적 HTML로):
  - `identity` 동일성: 시간이 지나도 "같은 것"으로 남는다는 것. 무엇이 같음을 결정하는지가 철학의 오래된 질문이다.
  - `convention` 규약주의: 어떤 구분이 세상에 원래 있는 게 아니라 사람들의 약속으로 정해진다는 생각.
- README 실험 표, PLAN 실험 상세·데이터 구조·개발 단계.
