# 설계: 공통 상단 바 + "다른 실험" 섹션

- 날짜: 2026-11-09
- 목적: 어느 페이지에서든 메인으로 돌아가고, 실험을 마친 뒤 다른 실험으로 이어지게 한다.

## 1. 상단 바 (모든 페이지)

- 왼쪽: `GEDANKEN LAB` 로고(IBM Plex Mono). 메인으로 가는 링크다.
- 오른쪽: 실험 페이지에만 `← 메인` 링크. 메인 페이지에는 없다.
- `position: sticky; top: 0`, 높이 약 48px, 종이색 배경, 아래 1px 잉크색 선.
- 마크업은 각 HTML에 직접 넣는다(JS 없이 표시, 화면 흔들림 없음). 스타일은 `css/base.css`의 `.site-bar`.
- 트롤리 장면 1의 `← 실험 목록` 링크는 상단 바와 겹치므로 지운다. 장면 2·3의 `← 이전 장면`은 유지한다.

## 2. "다른 실험 해보기" 섹션 (결과 화면 맨 아래)

- 현재 실험을 제외한 실험을 메인과 같은 카드로 보여 준다. `ready: true`면 링크 카드, 아니면 점선 "준비 중" 카드.
- 결과 화면의 `다른 실험 하러 가기 →` 버튼은 이 섹션으로 대체한다. `↺ 다시 실험하기`는 유지한다.

## 3. 실험 목록

- `js/experiments.js`: `export const EXPERIMENTS = [{ num, slug, title, field, blurb, ready }]`. 실험을 추가할 때 여기에 한 줄 넣는다.
- `js/other-experiments.js`: `renderOtherExperiments(container, currentSlug, rootPath)`가 카드를 그린다. `rootPath`는 사이트 루트까지의 상대 경로(트롤리에서는 `'../../'`).
- 메인 페이지 카드는 실험별 일러스트가 있어서 HTML에 그대로 둔다. 카드 스타일 `.exp`는 `index.html`의 `<style>`에서 `css/base.css`로 옮긴다.

## 4. 검증

- 1440px, 390px에서 메인/장면/결과 스크린샷, 가로 스크롤 없음.
- 스크롤 중에도 상단 바가 붙어 있고, 로고와 `← 메인`이 메인으로 간다.
- 트롤리 결과의 "다른 실험"에 #02, #03만 준비 중으로 나온다.
- `npm test` 통과, 콘솔 에러 없음.
