# 설계: EXP #03 맥스웰의 악마 (4단계)

- 날짜: 2026-11-09
- 시각 기준: 실험 노트 스타일(`css/base.css`). 별도 시안 없음.

## 1. 흐름 (`experiments/maxwell/index.html`)

1. **사전 질문** (`data-step="1"`): "악마가 열역학 2법칙을 깰 수 있을까?" A 깰 수 있다 / B 깰 수 없다.
2. **실험** (`data-step="2"`, 내부 단계 `sort` → `reveal`)
   - Canvas: 두 방, 가운데 벽의 문, 빠른 입자 20개(주황, 채운 원)와 느린 입자 20개(파랑, 빈 원). 양쪽 방에 10개씩 나눠 시작해서 처음 온도 차는 0. 문 위에 작은 악마.
   - `문 열기` 버튼을 누르고 있는 동안(또는 스페이스바) 문이 열린다.
   - 목표: 왼쪽 방을 뜨겁게. 양쪽 온도와 "방의 엔트로피" 막대 표시.
   - `sort`: 왼쪽 − 오른쪽 온도 차 ≥ 12이면(완벽한 악마로 시뮬레이션하면 중앙값 약 20초) "2법칙을 깼다?!" 배너 + `정말일까? →`. `건너뛰기`도 항상 있다.
   - `reveal`: 숨어 있던 기억 장부 공개(쌓인 기록 N개). `기억 지우기`를 눌러야 결과로 갈 수 있다. 지우면 버린 열이 생기고 전체 엔트로피(방 + 버린 열)가 처음 이상임을 막대와 기준선으로 보여 준다. 이후 기억 용량 8칸 제한: 다 차면 문이 잠기고 지우기로 풀린다.
3. **결과** (`data-step="result"`): 예측 적중 여부, 내 기록(통과 수, 버린 열, 최저 방 엔트로피, 전체 vs 처음), 다른 실험자 A/B 비율, 고찰(맥스웰 → 실라르드 → 란다우어 → 베넷, 2012년 실험 검증), 참고 문헌, 다시 실험하기, 다른 실험.

## 2. 모델

- `experiments/maxwell/sim.js` (순수): 논리 좌표 800×400, 벽 x=400, 문 y 150~250. 입자끼리는 충돌하지 않고 벽에서만 반사(속도 크기 불변). `createSim({ random })`, `step(sim, dt, doorOpen)` → 이번 스텝의 통과 목록, `temps(sim)` → `{ left, right }`(평균 v² × 상수, 섞인 상태 ≈ 30, 빈 방은 `null`), `counts(sim)`.
- `experiments/maxwell/entropy.js` (순수):
  - `roomEntropy(counts)`: 빠른/느린 입자 각각의 좌우 분포 이진 엔트로피 × 개수(비트). 다 섞이면 최대(40), 완전 분류면 0.
  - `createLedger(startEntropy)`: `record()`(통과 1회 = 기록 1비트), `erase(roomNow)` → 열 = max(지운 비트, 마지막 지우기 이후 줄어든 방 엔트로피). 따라서 지운 뒤에는 항상 방 + 버린 열 ≥ 처음.
- 엔트로피 막대는 개념도다. 화면에 "개념도 · 실제 비율 아님"을 표시한다.
