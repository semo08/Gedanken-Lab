# 설계: EXP #06 중국어 방 (8단계)

- 날짜: 2026-11-10
- 분야: 컴퓨터 · 체험 + 입장
- 시각 기준: 기존 실험의 실험 노트 스타일(`css/base.css`). 방 안은 종이 쪽지와 규칙서 카드.
- 짝 실험: EXP #05 이미테이션 게임. 튜링의 주장(#05)에 대한 존 설의 반박(1980).

## 1. 흐름 (`experiments/chinese-room/index.html`, `<section data-step>` 4개)

1. **상황**
   - 당신은 작은 방에 갇혀 있다. 방에는 규칙서 한 권과 기호 카드 상자가 있다. 기호는 한 번도 본 적 없는 글자다. 문 틈으로 기호가 적힌 쪽지가 들어오면, 규칙서를 보고 맞는 기호 카드를 골라 답 쪽지를 내보내면 된다.
   - 원래 실험은 중국어지만, 한국 사람은 한자를 조금씩 알아서 "전혀 모르는 글자"가 되도록 이 실험에서는 **가상의 문자**를 쓴다는 안내 한 줄. 실험 이름은 "중국어 방"을 유지한다.
2. **방 안** (쪽지 5장)
   - 들어온 쪽지(기호 2~4개) → 규칙서 펼침면(해당 규칙 1~3개) → 기호 카드 상자(8~12장)에서 골라 답 칸에 놓기 → `쪽지 내보내기`.
   - 규칙은 점점 복잡해진다.
     - 쪽지 1~2: 단순 대응. "◇△가 오면 ○□를 내보낸다."
     - 쪽지 3~4: 조건. "◇가 맨 앞이면 …, 아니면 …"
     - 쪽지 5: 앞 쪽지를 참고. "직전에 □를 내보냈다면 …" (대화 맥락을 기억하는 것처럼 보이게)
   - 틀리면 규칙서의 해당 줄이 흔들리며 다시 해 보라고 한다(정답을 보여 주지 않음, 3번 틀리면 정답 칸 표시). 맞으면 쪽지가 문 밖으로 나가고, 밖에서 기호로 된 답장이 들어온다.
   - 진행 칸: 쪽지 5장.
3. **반전: 방 밖에서 본 장면**
   - 같은 대화를 바깥 사람 시점으로 번역해서 보여 준다. 왼쪽 = 기호, 오른쪽 = 뜻.
     - 예: "오늘 기분 어때?" ↔ 당신의 답 "비가 와서 좀 나른해. 너는?"
   - 바깥 사람의 한 줄 평: "방 안 사람은 이 언어를 유창하게 하는 게 분명해!"
   - 질문(투표): "방 안의 당신은 이 언어를 전혀 몰랐다. 그럼 **이 방**은 이 언어를 이해한 걸까?"
     - A 아무도 이해하지 못했다
     - B 사람 + 규칙서, 방 전체는 이해했다
     - C "이해"의 기준이 애초에 모호하다
4. **결과**
   1. 나의 입장: 내 답에 해당하는 입장 카드 강조 + 3개 나란히(슈뢰딩거 결과 화면과 같은 방식).
   2. 다른 실험자들: A/B/C 3칸 막대 + 범례 + 참여 수.
   3. 내 방 안 기록: 쪽지 5장, 틀린 횟수.
   4. 고찰: 설의 핵심은 "문법(기호 조작)만으로는 의미가 생기지 않는다"는 것. 컴퓨터 프로그램이 하는 일이 방 안의 당신이 한 일과 같다면, 튜링 테스트를 통과해도 이해한 건 아니라는 주장이다. 요즘 대규모 언어 모델에도 똑같은 질문이 던져지고 있고, 아직 결론은 없다.
   5. "EXP #05 이미테이션 게임" 링크 카드(아직 안 했다면).
   6. 참고 문헌, `↺ 다시 실험하기`, "다른 실험 해보기".

## 2. 입장 매핑 (`experiments/chinese-room/stance.js`, 순수)

| 답 | 입장 키 | 이름 | 한 줄 |
|---|---|---|---|
| A | `searle` | 설의 입장 (존 설) | 기호를 규칙대로 옮겼을 뿐, 뜻은 어디에도 없었다. |
| B | `systems` | 시스템 반론 | 뉴런 하나가 한국어를 모르듯, 이해는 부품이 아니라 전체에 있다. |
| C | `other-minds` | 다른 마음 반론 | 다른 사람이 이해하는지도 우리는 행동으로만 안다. 기계에게만 더 엄격할 이유가 있을까? |

`stance('B')` → `{ key: 'systems', name, line }`. `STANCES`(3개, 표시 순서 고정)도 export한다. 설은 1980년 논문에서 두 반론을 직접 소개하고 재반박했다. 결과 화면에 각 입장에 대한 설의 재반박도 한 줄씩 넣는다.

## 3. 기호와 규칙 (`experiments/chinese-room/glyphs.js`, `rules.js`)

- 기호 12개: 선과 도형을 조합한 가상 문자. 인라인 SVG `path` 데이터로 정의(폰트 의존 없음). 실제 문자와 닮지 않게 한다(한글 자모, 한자, 알파벳과 겹치지 않는지 확인).
- 각 기호에는 내부 id(`g01`~`g12`)와, 결과 화면 번역에 쓰는 "뜻"이 있다. 가상 언어는 단어 단위 대응(기호 1개 = 단어 1개)으로 단순하게.
- `rules.js` (순수): 쪽지 5장의 데이터와 정답 판정.
  - `expected(noteIndex, history)` → 정답 기호 id 배열 (쪽지 5는 `history` 참조)
  - `check(noteIndex, answer, history)` → boolean
- 규칙서 화면은 규칙 데이터를 그대로 그린다(텍스트 설명은 "이 모양 → 이 모양" 그림으로만, 뜻은 숨김).
